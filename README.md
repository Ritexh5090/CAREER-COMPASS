# Career Compass

Career Compass is a short, student-friendly quiz that helps Class 10 students explore a suitable Class 11 stream: Engineering, Medical, Commerce, Arts & Humanities, or Pure Science.

## What it includes

- Six-question interest quiz with English and Hindi support
- A top match and strong second match
- Stream details, typical entrance exams, timelines, and rough costs
- Downloadable result card and copyable summary
- Responsive layout for phones, tablets, and desktops

## Built with

- React
- Vite
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open the local address shown in the terminal, usually `http://localhost:5173`.

## Build for production

```bash
npm run build
```

The finished website is created in the `dist` folder.

## Deploy with GitHub Pages

This repository includes a GitHub Actions workflow in `.github/workflows/deploy.yml`.

1. Create a public GitHub repository and push this project to its `main` branch.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **GitHub Actions**.
4. Push a change to `main`; GitHub will build and publish the website automatically.

Your live site will be available at `https://<github-username>.github.io/<repository-name>/`.
